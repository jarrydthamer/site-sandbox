EXEC_PATH // HOW IT WORKS

Evidence in. Verified waste out.

  1. 1. Ingest: Urbyte receives agreed billing, allocation and usage evidence through a controlled file-based process. Current proof uses asynchronous evidence ingestion.
  2. 2. Validate: The system checks evidence completeness, billing-period continuity, allocation structure and usage validity.
  3. 3. Verify: Urbyte calculates qualifying unused allocation using the correct method for individual, pooled or mixed fleet structures.
  4. 4. Govern: Keelo receives verified conditions, applies authority and ownership controls, and governs any authorised action through a controlled external boundary.
  5. 5. Reconcile: Every service is reconciled as actionable verified, verified with no action required, or unverifiable. Receipts and outcomes remain linked to source evidence.
